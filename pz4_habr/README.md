# Аналитический калькулятор объёма возвращаемых данных

Это небольшой **вспомогательный** модуль ПЗ-4 для воспроизводимой проверки формул. Он не запускает модель GPT-2, Ray Actors, сетевой обмен или сравнительные эксперименты. **Полная практическая реализация находится в [research/](../research/README.md).**

## Запуск

Требуется Python 3.10+; дополнительные зависимости не нужны. Из корня репозитория:

```bash
cd pz4_habr
python3 traffic_model.py
python3 -m unittest discover -s . -p 'test_*.py' -v
```

Для параметров контрольного расчёта: `B=1`, `L₀=5`, `T=20`, `V=50257`, логит `float32` (4 байта), идентификатор `int64` (8 байт):

| Вариант | Сырой объём выхода последнего исполнителя → управляющий процесс |
| --- | ---: |
| D0 — полные логиты каждой позиции | 58 298 120 байт (около 55,60 МиБ) |
| D1 — вычисление полных логитов, возврат последней позиции | 4 020 560 байт (около 3,83 МиБ) |
| D2 — расчёт логитов только последней позиции | 4 020 560 байт (около 3,83 МиБ) |
| D3 — выбор токена (`argmax`) внутри последнего исполнителя | 160 байт |

При D1 и D2 одинаковый размер возвращаемого массива, **но не обязательно одинаковый объём вычислений**. Указанные значения относятся только к полезной нагрузке выходного направления; не учитывают hidden states, маски, служебную сериализацию Ray или транспортные заголовки. Это **расчёт**, а не измерение фактической сети или доказательство ускорения.

Проверяемые экспериментальные результаты B0/B1/D0–D3 и DistilGPT2 доступны в [отчёте research](../research/RESEARCH_EVIDENCE.md).
