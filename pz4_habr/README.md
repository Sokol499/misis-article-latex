# Проверяемая аналитическая модель обмена

Эти файлы сопровождают технический материал о послойном инференсе GPT-2-подобной модели на Ray для ПЗ-4. Они **не запускают Ray**, не реализуют оптимизации D1–D3 и не измеряют сетевой трафик или ускорение.

## Запуск

Требуется Python 3.10+ (стандартная библиотека).

```bash
cd pz4_habr
python3 traffic_model.py
python3 -m unittest discover -s . -p 'test_*.py' -v
```

Для параметров контрольной генерации **B=1, L0=5, T=20, V=50257, float32=4 байта, int64=8 байт**:

| Вариант | Сырой полезный объём завершающий shard → driver |
| --- | ---: |
| D0: полные логиты всех позиций | 58 298 120 байт (~55,60 МиБ) |
| D1: возвращаем только логиты последней позиции | 4 020 560 байт (~3,83 МиБ) |
| D2: вычисляем только логиты последней позиции | 4 020 560 байт (~3,83 МиБ) |
| D3: локальный argmax, возвращаем int64 ID | 160 байт |

D1 и D2 одинаковы по **размеру возвращаемого сообщения**, но могут различаться по числу вычислений. Значения — арифметические оценки по форме тензоров; не включают hidden states, маски, Ray RPC/сериализацию и сетевые заголовки.

Исходные экспериментальные данные о CPU-прототипе и план дальнейших исследований описаны в [научной рукописи](../README.md).
