# ПЗ-3 — Научное письмо (НИТУ МИСИС)

**Студент:** Соколов Филипп Олегович, БПМ-23-ПО-3.  
**Руководитель НИР:** Курочкин И. И.  
**Название статьи:** Исследование распределённого инференса Transformer-моделей с послойным шардированием на базе Ray.

## Содержание

Рукопись содержит введение, анализ исследований, постановку задачи, описание методов и список из 12 проверяемых источников. Работа развивает ранее реализованный CPU-прототип из НИР. Оптимизация обмена, динамическое программирование и расширенный набор нагрузочных сценариев изложены как предлагаемые методы, а не как выполненные эксперименты.

## Сборка

Сохранён оригинальный `misisarticle.cls` и оригинальный GitHub Actions workflow преподавателя (`.github/workflows/build.yml`). Главный файл — `article.tex`. Список литературы размещён в `references.tex` и использует нативный `thebibliography` класса — Biber не требуется.

Сборка локально: `tectonic article.tex` (или `xelatex article.tex` дважды). При каждом push исходный workflow создаёт артефакт `article.pdf`.

Для автоматической проверки структуры: `python3 scripts/check_manuscript.py`.

## Статус

На этапе ПЗ-3 статья не обязана включать эксперимент или заключение. Все будущие действия и ожидаемые результаты обозначены как планы. Исполнители Ray в исходной НИР — три логических контейнерных узла на одной физической машине, а не три независимых сервера.
