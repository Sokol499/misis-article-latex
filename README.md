# Исследование распределённого инференса Transformer-моделей с послойным шардированием на базе Ray

**Автор:** Соколов Филипп Олегович (БПМ-23-ПО-3), кафедра инженерной кибернетики НИТУ МИСИС.  
**Научный руководитель НИР:** Курочкин И. И.  
**Основа оформления:** [LaTeX-шаблон преподавателя](https://github.com/sadekovlar/misis-article-latex); данный репозиторий — его форк.

## Научная задача

Исследуется послойное выполнение Transformer-модели на нескольких исполнителях Ray с учётом затрат на вычисления, обмен промежуточными тензорами и ограничений памяти. Работа направлена на воспроизводимую оценку коммуникационных расходов и изучение способов выбора границ разбиения модели.

**Уже выполнено в НИР:** CPU-прототип на основе `sshleifer/tiny-gpt2`, разделение компонентов модели между тремя логическими Ray-узлами в Docker Compose на **одной физической машине**, демонстрация генерации и расчётная оценка объёма тензоров.

**Предлагается исследовать:** четыре варианта обработки логитов (от полного тензора до локального `argmax`), математическую задачу распределения слоёв с ограничениями памяти, подход на основе динамического программирования и сравнение реализаций на авторском наборе нагрузочных сценариев. **Экспериментальная эффективность этих улучшений пока не подтверждена**.

## Готовый PDF и автоматическая сборка

**[GitHub Actions — Build](https://github.com/Sokol499/misis-article-latex/actions/workflows/build.yml)**: после изменения файлов или ручного запуска (`Run workflow`) рабочий процесс компилирует `article.tex` с помощью Tectonic и сохраняет артефакт **`article.pdf`**.

**[Успешная сборка, подтверждённая для ПЗ-3](https://github.com/Sokol499/misis-article-latex/actions/runs/41916560963)** — в разделе *Artifacts* скачивается `article.pdf`. Артефакт `example.pdf` относится к демонстрационному примеру исходного шаблона, а не к этой статье.

Локально (при установленном Tectonic):

```bash
make article                   # PDF: build/article.pdf
python3 scripts/check_manuscript.py  # Проверка разделов и библиографии
make dist                      # ZIP с исходниками статьи для переноса
```

## Структура репозитория

| Путь | Назначение |
| --- | --- |
| `article.tex` | Главный файл: название, автор, аннотация, ключевые слова и подключение разделов |
| `sections/` | Четыре содержательных раздела статьи |
| `references.tex` | Список литературы, подключаемый из `article.tex` |
| `scripts/check_manuscript.py` | Локальная структурная проверка ссылок и разделов |
| `misisarticle.cls` | **Неизменённый класс оформления преподавателя** |
| `.github/workflows/build.yml` | Сборка и публикация PDF через GitHub Actions |
| `example/` | Пример из шаблона преподавателя, нужен для исходной проверочной сборки |
| `Makefile` | Команды локальной сборки и создания переносимого архива |

Файлы `.gitignore`, `LICENSE` и `CHANGELOG.md` оставлены от исходного шаблона; они не являются случайными файлами.

## Научная добросовестность

Публикация различает выполненные действия и запланированные методы. Расчётные оценки трафика не выдаются за фактические межмашинные измерения. Наличие трёх логических Ray-узлов не означает использование трёх физических серверов. При дальнейшем развитии работы предполагается фиксировать исходники, сценарии, параметры среды и измеренные результаты для воспроизводимости.
